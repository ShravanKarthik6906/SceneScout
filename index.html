Paste a Google Maps API key (with the Maps Embed API enabled) to get live Street View embedded inside listing pages. Without a key, Street View and Google Earth still open in a new tab — no key required.

About the data: listings and 3D twins here are simulated for demonstration. In production, inventory would come from licensed listing feeds (MLS/Zillow partner API, Peerspace, Giggster) and twins would be reconstructed from listing photos via photogrammetry (Matterport SDK, NeRF / Gaussian splatting). Scraping Zillow directly violates their terms of service, so this prototype keeps that boundary clean.
